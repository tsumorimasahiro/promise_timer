# ぽちログ レビューガイド

## まずSimulator版を開く

1. [Simulator版 ZIP](pochilog-1.04-build63-simulator-unsigned.zip)を展開します。
2. Xcodeの「Open Developer Tool」からSimulatorを起動し、iOS 17以降の端末を選びます（ウィジェットも見る場合）。
3. 展開した`promise_timer.app`を、起動中のSimulator端末へドラッグします。
4. 初回設定をやり直す場合は、Simulatorからぽちログを削除して再インストールします。

## 今回の体験を確認する

1. 初回設定で「本を1ページ読む」「布団に入る」「問題を1問解く」など、好きな約束を1〜3個選びます。
2. ぽちに名前をつけ、毛色・首輪・チャームを選びます。
3. 画面下の小さな景色プレビューに、選んだテーマが並ぶことを見ます。
4. 約束をひとつ記録します。ぽちが反応し、選んだテーマに応じて景色のしるしが育つ流れを確認します。
5. 絆カードからシェア画面を開きます。ぽちの見た目、絆、テーマの成長が反映され、習慣の具体名は出ないことを確認します。

## 言語を切り替える

Simulatorの「設定」>「一般」>「言語と地域」で日本語、English、한국어、简体中文、繁體中文（台灣）を切り替え、ぽちの案内・習慣名・ウィジェット名を確認できます。ウィジェット表示はiOS 17以降が必要です。

## 実機用

[iPhone実機版 ZIP](pochilog-1.04-build63-release-unsigned.zip)は署名なしです。iPhoneへ入れるには、開発チームによる署名が必要です。

このレビュー版はReleaseビルド済みですが、作成環境ではMacのロックとSimulatorサービスの不調により、実画面の起動確認はできていません。
