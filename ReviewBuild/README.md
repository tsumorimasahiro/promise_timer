はじめて確認する場合は[レビューガイド](START_HERE.md)から進めてください。

## iPhone実機向け

- アプリ本体: iOS arm64、最小対応OS 16.6、Bundle ID `max.promise-timer`
- ウィジェット: 最小対応OS 17.0
- [署名なしデバイス版 ZIP](pochilog-1.04-build63-release-unsigned.zip)

## Simulator向け

- iOS Simulator arm64 / x86_64、アプリとウィジェットを含む
- [署名なしSimulator版 ZIP](pochilog-1.04-build63-simulator-unsigned.zip)
- 展開後の`promise_timer.app`を、起動中のiOS Simulator端末へドラッグしてインストールできます。アプリはiOS 16.6以降、ウィジェットはiOS 17以降のSimulator runtimeが必要です。

## 共通情報

- 2026-10-21 04:02 JSTにiPhone実機向けとSimulator向けの現行ソースReleaseビルドに成功。アプリとウィジェットはともに1.04 (build 63)、署名なし。
- アプリとウィジェットの言語: 日本語、English、한국어、简体中文、繁體中文（台灣）
- アプリ内・ウィジェット内の英語、韓国語、簡体字、台湾繁体字リソースのキーを照合し、各言語の未使用の古いウィジェット文言も整理済み。
- 初回に選んだ習慣がぽちの景色に反映され、約束を叶えるたびテーマごとのモチーフが成長します。
- 複数の好きなテーマを選ぶと、ホームの風景上部に全テーマのシンボルが並びます。もっともよく続けているテーマが背景の色や景色を決めます。
- ぽちとの絆やテーマ成長に合わせて風景がなめらかに変化します。視差効果を減らす設定中はアニメーションを停止します。
- 初回に最大6テーマを選べます。風景内のテーマバッジ、成長一覧、シェアカードには選択テーマをすべて表示します。
- 初回設定は28個の習慣から選べます。読書・おやすみ・学びなど選択したテーマは、プレビューにすべて表示されます。カスタム習慣名からも読書テーマを判定します。
- 読書好き・睡眠を整えたい・勉強したい人が自分に合う小さな約束を選べるよう、「本を1ページ読む」「布団に入る」「問題を1問解く」を追加。それぞれ読書・睡眠・学びの景色に成長が反映されます。
- ホームには選んだ全テーマの累計成長カードが並び、成長段階と次までの達成回数を表示します。
- 個別習慣の進捗は週次目標として表示し、累計テーマ成長と区別しています。
- 複数テーマを選んだ場合、達成回数が最も多いテーマをぽちの代表の景色とシェアカードの背景に反映します。
- シェアカードのテーマ印にも代表テーマを必ず含めます。
- シェアカードには選択したすべてのテーマを2行までにまとめて成長段階を表示します。テーマを追加したときもカードを更新します。
- 絆が育つ前から、ぽちは寝息のように小さく動き、約束を叶えると跳ねて喜びます。絆が育つと歩き出します（視差効果を減らす設定では静止表示）。
- 習慣ウィジェットは達成前に習慣アイコン、達成後に選んだ首輪とチャームをつけたぽちを表示します。
- ウィジェットギャラリーの名前と説明も5言語でぽち中心に表示します。
- 週の始まりを端末の地域設定に合わせ、アプリとウィジェットの曜日ラベルを達成日の並びと一致させます。
- 習慣を編集しても、選択したカテゴリーとテーマが保たれます。
- 初回選択は最大6個、まず1〜3個から始める案内を5言語に対応。
- プロフィール案内で、名前・毛色・首輪・チャームを選べることを5言語で表示。選べる習慣数も自動表示。
- シェア画像のぽちに、現在選択中の毛色とチャームを明示して渡し、プロフィール表示と揃える。
- 初回選択に読書・睡眠・勉強のクイックフィルターを追加。選択中のテーマに合わせて画面下の景色プレビューへ移動。
- 約束を達成した時点のテーマを絆の記録として保存。約束を削除しても、育ったテーマの景色とシェアカードに思い出が残る。
- シェアカードの背景色も読書・睡眠・学びなどのテーマに合わせて変化。
- ぽちの名前を空欄や未変更の初期値にした場合も、表示中の言語に合わせて名前を表示します。
- ホームのプロフィール編集ボタンは、名前だけでなく毛色・首輪・チャームも変更できると5言語のVoiceOver読み上げで案内します。
- ぽちの毛色を「きなこ」「みるく」から選べます。選択はアプリとウィジェットで共有し、歩くポーズやSNSシェアにも反映します。
- 保存済みの標準習慣名は、端末の表示言語を変えても現在の言語で表示します。標準名を編集した場合やユーザー自身が追加した名前は保持します。
- App Store Connect向けに5言語の商品名・サブタイトル・キーワード・説明文・スクリーンショット見出し案を用意。登録前の文字数・キーワードbyte数を確認しています（原稿: `STORE_LISTING_COPY.md`）。
- 初回設定で選んだテーマごとの小さな景色を並べて表示し、読書・睡眠・学びなど「自分の好き」がぽちの世界に映ることを伝えます。
- テーマの成長に合わせて、景色にきらめきやハートが増えます。
- ホームのテーマカードをタップすると、専用の景色、達成回数、次の成長までの回数を見られます。
- テーマカードから詳細画面を開け、専用の景色とポチ、累計達成回数、次の成長までの回数を表示します。
- SNSシェア画像の見出し、絆の称号、締めのコピーを選択中の5言語に切り替えます。
- 韓国語・中国語の「睡前」「취침」など、カスタム習慣の多言語表現も読書・睡眠・学びの景色へ結びつけます。
- 初回に選んだ複数テーマの景色は横スクロールで最後まで確認できます。
- ホームのテーマ詳細から、そのテーマの景色と成長段階をシェアできます。
- テーマ詳細を開いたまま記録や見た目を変えても、シェア画像を最新の絆とプロフィールに更新します。
- シェア画像のポチ名・テーマ名・絆の称号が長い場合も、中央揃えで2行に収まるようにします。
- 初回の習慣選択中、テーマごとのミニ景色は画面下部に固定され、追加したテーマまで自動でスクロールします。
- ZIPはビルド済みの`promise_timer.app`を格納。iPhoneへ直接インストールするには、利用者の開発チームで署名が必要。
